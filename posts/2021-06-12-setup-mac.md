# Setting up a new Mac

Here is a screenshot.

![](setup.png "Here is how my terminal looks after the configuration")

I will now discuss how I setup a new Mac. I use homebrew. It makes it very easy to maintain all the packages up to date.

### Install homebrew and some pertinent packages

`xcode-select --install`

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Install git

`brew install git`

Install Git-Credential-Manager

```
brew tap microsoft/git
brew install --cask git-credential-manager-core
```

Install powerline fonts

```
git clone https://github.com/powerline/fonts
cd fonts
./install.sh
```

Use powerline fonts in shell

Go to Terminal -> Preferences
Change font to powerline
I am using Roboto Mono Light Powerline 18pt

```
git clone git://github.com/stephenway/monokai.terminal.git

cd monokai.terminal

open monokai.terminal

```

(set this theme as default)

Install Zoom

`brew install --cask zoom`

Install Firefox

`brew install --cask firefox`

Install VSCode

`brew install --cask visual-studio-code`

Install OBSStudio

`brew install --cask obs`

VLC

`brew install --cask vlc`

wget

`brew install wget`

## Python Environment Setup with uv

### Install uv

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
```

Check installation:

```bash
uv --version
```

### Install Python 3.12

(PyTorch GPU wheels are available only up to 3.12.)

```bash
uv python install 3.12
```

### Create a global environment

```bash
uv venv ~/.uv/nb-base --python 3.12
source ~/.uv/nb-base/bin/activate
```

Optional auto-activation:

```bash
echo 'source ~/.uv/nb-base/bin/activate' >> ~/.zshrc
```

### Install core packages

```bash
uv pip install -U pip setuptools wheel
uv pip install -U jupyterlab ipykernel numpy pandas scipy matplotlib seaborn scikit-learn tqdm requests
```

### Install PyTorch (Mac - CPU/MPS)

For Mac (Apple Silicon M1/M2/M3 with Metal Performance Shaders support):

```bash
uv pip install torch torchvision torchaudio
```

Verify:

```bash
python -c "import torch; print(torch.__version__); print('MPS available:', torch.backends.mps.is_available())"
# → e.g. 2.5.0
# → MPS available: True (on Apple Silicon Macs)
```

**Note:** Macs don't support CUDA. Apple Silicon Macs use MPS (Metal Performance Shaders) for GPU acceleration. Intel Macs will use CPU only.

### Register the Jupyter kernel

```bash
python -m ipykernel install --user --name nb-base --display-name "Python (nb-base)"
```

### Verify installation

```bash
which python
python --version
jupyter kernelspec list
```

Expected:

```
/Users/<user>/.uv/nb-base/bin/python
Python 3.12.x
nb-base   /Users/<user>/.local/share/jupyter/kernels/nb-base
```

### Connect to VSCode

Open any `.ipynb` file

Kernel picker → Select Another Kernel → Jupyter Kernel → Python (nb-base)

Optional workspace config → `.vscode/settings.json`:

```json
{
  "python.defaultInterpreterPath": "/Users/<user>/.uv/nb-base/bin/python",
  "jupyter.jupyterServerType": "local"
}
```

You can also configure Python interpreter:
Cmd + Shift + p -> Select Python Interpreter -> Point to `~/.uv/nb-base/bin/python`
![](vscode-interpreter.png "Setting Python Interpreter in VSCode")

## Terminal Setup with Ghostty

### Install Ghostty

[Ghostty](https://ghostty.org/) is a modern, fast, and feature-rich terminal emulator with excellent graphics protocol support.

```bash
brew install --cask ghostty
```

Ghostty supports the kitty graphics protocol, which enables displaying images directly in the terminal.

### Terminal Image Viewers

Install image viewers that work with Ghostty's graphics protocol:

```bash
# viu - Fast image viewer using kitty protocol
brew install viu

# chafa - Versatile image viewer with multiple protocol support
brew install chafa
```

Usage:

```bash
# View an image
viu image.jpg

# View with specific width
viu -w 80 image.png

# Using chafa
chafa image.jpg
```

### File Manager with Preview

Install [yazi](https://github.com/sxyazi/yazi) - a modern terminal file manager with image preview support:

```bash
brew install yazi ffmpegthumbnailer font-symbols-only-nerd-font
```

Launch yazi:

```bash
yazi
```

Key bindings:
- `j/k` or arrow keys - Navigate files
- `Enter` or `l` - Open file/directory
- `h` - Go to parent directory
- `Space` - Select/deselect file
- `T` - Toggle preview pane
- `q` - Quit

## macOS Dock Customization

### Disable Dock Magnification

Prevent the Dock from changing size when hovering:

```bash
defaults write com.apple.dock magnification -bool false
killall Dock
```

### Enable Auto-Hide with Fast Animation

Keep screen space consistent by auto-hiding the Dock:

```bash
# Enable auto-hide
defaults write com.apple.dock autohide -bool true

# No delay before showing
defaults write com.apple.dock autohide-delay -float 0

# Fast animation (0.1s)
defaults write com.apple.dock autohide-time-modifier -float 0.1

# Apply changes
killall Dock
```

For even faster animation:

```bash
# Near-instant (0.01s)
defaults write com.apple.dock autohide-time-modifier -float 0.01
killall Dock
```

To revert auto-hide:

```bash
defaults write com.apple.dock autohide -bool false
killall Dock
```

### Set Dock Position

```bash
# Left side
defaults write com.apple.dock orientation -string left
killall Dock

# Bottom (default)
defaults write com.apple.dock orientation -string bottom
killall Dock

# Right side
defaults write com.apple.dock orientation -string right
killall Dock
```

### Updating packages

To update packages in your uv environment:

```bash
source ~/.uv/nb-base/bin/activate
uv pip install -U <package-name>
```

To update all packages:

```bash
uv pip list --outdated
uv pip install -U <list-of-packages>
```
